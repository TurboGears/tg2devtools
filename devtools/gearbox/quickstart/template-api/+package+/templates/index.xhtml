Using API Token (Bearer Authentication)

Use the API tokens shown above to authenticate via the Authorization header:

# List all movies
curl -H "Authorization: Bearer abc123def456ghi789jkl012mno345" \
     http://localhost:8080/api/movies

# Create a new movie
curl -X POST \
     -H "Authorization: Bearer abc123def456ghi789jkl012mno345" \
     -H "Content-Type: application/json" \
     -d '{"title": "Inception", "year": 2010, "description": "A mind-bending movie"}' \
     http://localhost:8080/api/movies

# Get a specific movie
curl -H "Authorization: Bearer abc123def456ghi789jkl012mno345" \
     http://localhost:8080/api/movies/1

# Update a movie
curl -X PUT \
     -H "Authorization: Bearer abc123def456ghi789jkl012mno345" \
     -H "Content-Type: application/json" \
     -d '{"title": "Inception 2", "year": 2025}' \
     http://localhost:8080/api/movies/1

# Delete a movie
curl -X POST \
     -H "Authorization: Bearer abc123def456ghi789jkl012mno345" \
     http://localhost:8080/api/movies/1/_delete

# Access admin endpoint (requires manage permission)
curl -H "Authorization: Bearer abc123def456ghi789jkl012mno345" \
     http://localhost:8080/demo/admin

🧹 Cleanup Demo Parts

Note: Once you're ready to build your own API, you can remove the demo parts.

Run these commands from your project root:

cd ${project}
rm -rf controllers/api/movies.py controllers/demo.py model/movie.py tests/functional/test_movies.py
gearbox patch controllers/root.py DemoController -d
gearbox patch controllers/api/__init__.py Movie -d
gearbox patch model/__init__.py movie -d
gearbox patch websetup/bootstrap.py movie -d
